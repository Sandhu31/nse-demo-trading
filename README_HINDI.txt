NSE DEMO TRADING BOT - ANDROID SETUP

Yeh package Demo/Paper Trading ke liye hai. Yeh broker se connect nahi hota
aur real orders place nahi karta.

Android par chalane ka aasaan tareeka:
1. ZIP ko download karke extract karein.
2. GitHub par account banayein / sign in karein.
3. New public repository banayein, naam: nse-demo-trading-bot
4. Is folder ki 3 files repository ke root mein upload karein:
   - nse_demo_bot.py
   - requirements.txt
   - README_HINDI.txt
5. Streamlit Community Cloud par sign in karein.
6. "Create app" / "Deploy an app" chunein.
7. GitHub repository select karein.
8. Main file path mein nse_demo_bot.py likhein.
9. Deploy karein.
10. Deploy hone ke baad mila HTTPS link Android Chrome mein kholein.
11. Chrome menu > Add to Home screen se home screen par shortcut bana sakte hain.

Note:
- Internet connection zaroori hai.
- Yahoo Finance data delayed/adjusted ho sakta hai; availability guaranteed nahi.
- Backtest future profit ki guarantee nahi deta.
- Is version mein real-money trading ya broker API nahi hai.
- Password, API key, OTP ya broker login kisi ke saath share na karein.
